# Tikat - Studio Thiết Kế & Phát Triển Website, Web App Chuyên Nghiệp

Official Website: [https://tikat.com](https://tikat.com)

Tikat (tikat.com) là studio chuyên thiết kế & lập trình website cao cấp, SaaS, portal quản trị doanh nghiệp và các giải pháp web full-stack hiệu năng cao (PageSpeed 98+, Core Web Vitals <0.8s).

## Công nghệ sử dụng
- **Framework**: Next.js 15 / 16 (App Router), React 19, TypeScript
- **Styling**: Tailwind CSS v4, Motion (Framer Motion)
- **Icons**: Lucide React
- **Tối ưu**: Full Schema.org JSON-LD, SEO On-Page, OpenGraph, GEO Meta tags

## Khởi chạy dự án (Local Development)

```bash
npm install
npm run dev
```

Truy cập [http://localhost:3000](http://localhost:3000) trên trình duyệt.

## Build Production

```bash
npm run build
npm run start
```
